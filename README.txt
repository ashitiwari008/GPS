GPS Location Simulator – iPhone V1

1. Unzip the folder.
2. Open index.html in Safari or host the folder on a web server.
3. Enter Latitude and Longitude manually.
4. Tap Set Location.
5. The selected point is displayed on the map and saved for the next opening.

Important: This is an in-app simulated location only. It does not change the iPhone system GPS or the location reported to other apps/services.
